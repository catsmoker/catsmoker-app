## Acerca del proyecto

**CatSmoker** es un conjunto de herramientas para juegos de Android diseñado para optimizar los juegos compatibles, desbloquear opciones de configuración adicionales y supervisar el rendimiento del dispositivo.

## Funciones

- **Optimización:** suplantación de identidad del dispositivo, configuración de FPS y controles de resolución y densidad de pantalla.
- **Herramientas para juegos:** superposición de FPS en tiempo real, supervisión de CPU y RAM, y medición de temperatura y consumo de energía.
- **Personalización:** mira de apuntado superpuesta, DNS para juegos y editor de configuración de juegos.
- **Sistema:** integración con acceso root y Shizuku, diagnósticos y registros del sistema.
- **Biblioteca de juegos:** descubrir, iniciar y administrar los juegos instalados.

### Instalación

**Opción A — Dispositivos con acceso root (LSPosed / Vector)**

Requisitos: Magisk, APatch o KernelSU.

1. Instala y activa una sola implementación de Zygisk:
   - [ZygiskNext](https://github.com/LSPosed/ZygiskNext/releases)
   - [NeoZygisk](https://github.com/JingMatrix/NeoZygisk/releases)
   - [ReZygisk](https://github.com/PerformanC/ReZygisk)
2. Instala un solo módulo de framework:
   - **Recomendado:** [Vector](https://github.com/JingMatrix/Vector/releases)
   - Alternativa: [LSPosed](https://github.com/LSPosed/LSPosed)
3. Reinicia el dispositivo.
4. Instala CatSmoker y concede acceso root.
5. Abre el administrador de Vector/LSPosed, activa el módulo CatSmoker y selecciona los juegos de destino.
6. Fuerza la detención de los juegos seleccionados y vuelve a iniciarlos.

**Importante:** utiliza una sola implementación de Zygisk y un solo módulo de framework.

**Opción B — Dispositivos sin root (Shizuku)**

1. Instala [Shizuku Next](https://github.com/ShizukuNext/ShizukuNext) o la [versión oficial de Shizuku](https://play.google.com/store/apps/details?id=moe.shizuku.privileged.api).
2. Inicia Shizuku mediante la depuración inalámbrica o ADB.
3. Instala CatSmoker y concede el permiso de Shizuku.
4. Selecciona tu juego y utiliza las herramientas disponibles que funcionan mediante Shizuku.

Algunas operaciones con archivos pueden requerir permisos adicionales mediante el selector de archivos de Android o un administrador de archivos como ZArchiver.

</details>

### Unirse a la prueba cerrada

La versión de Google Play está disponible actualmente mediante una prueba cerrada.

1. Únete al grupo de Google: **catsmoker-apps@googlegroups.com**
2. Espera hasta cinco minutos para que se actualice el acceso.
3. Abre la [página de pruebas de Google Play](https://play.google.com/apps/testing/com.catsmoker.app).
4. Regístrate en la prueba e instala CatSmoker desde Google Play.

## Juegos compatibles

CatSmoker es compatible con más de 50 juegos, entre ellos:

- PUBG Mobile (todas las variantes compatibles).
- Genshin Impact.
- Honkai: Star Rail.
- Wuthering Waves.
- GRID Autosport.
- Y muchos más.

Solicita la inclusión de un juego mediante [GitHub Issues](https://github.com/catsmoker/catsmoker-app/issues), [Discord](https://discord.com/invite/HQC5BwcXtS) o [Telegram](https://t.me/CATSM0KER).

## Compatibilidad

- **Versión mínima de Android:** 8.1 (API 27).
- **Con root:** Magisk, APatch o KernelSU con una configuración compatible de Zygisk/framework.
- **Sin root:** Shizuku o métodos manuales de acceso compatibles.

Entre los dispositivos probados se encuentran:

- POCO X3 NFC
- Nothing Phone (2a)
- Xiaomi Redmi Note 14
- Lenovo Legion Tab
- Realme 9 Pro Plus

## Compilar desde el código fuente

Requisitos: Android Studio, JDK 17, Android SDK y el NDK configurado para el proyecto.

```bash
bash ./gradlew :app:assembleFullDebug :app:assemblePlaystoreDebug
```

En la rama `main` se mantienen dos variantes de Gradle:

| Variante | Tarea de compilación |
|---|---|
| GitHub completa | `:app:assembleFullRelease` |
| Google Play | `:app:assemblePlaystoreRelease` |

Consulta el [flujo de trabajo de las variantes](docs/FLAVOR_WORKFLOW.md).

## Privacidad

- **Prioridad local:** los ajustes, perfiles, copias de seguridad y registros permanecen en tu dispositivo.
- No hay sistema de cuentas ni servidor backend gestionado por el proyecto.
- Los registros y las grabaciones solo salen de tu dispositivo cuando decides compartirlos.
- La comprobación de actualizaciones utiliza la API pública de versiones de GitHub.
- La versión completa utiliza anuncios de Start.io. La versión de Google Play utiliza anuncios de AdMob.

Lee la Política de privacidad y los Términos completos dentro de la aplicación, en **Acerca de → Legal**.

## Aviso legal

Modificar archivos de juegos o suplantar la identidad del dispositivo puede infringir las condiciones de servicio de determinados juegos. Utiliza CatSmoker de forma responsable. Los desarrolladores no se hacen responsables de bloqueos de cuentas, problemas de hardware ni bucles de reinicio.
