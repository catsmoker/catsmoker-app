**CatSmoker** es una utilidad de optimización para Android enfocada en juegos compatibles. Combina integraciones del sistema, herramientas para editar archivos de juego, métricas en tiempo real y controles orientados a gaming en una sola aplicación.

## Visión general

CatSmoker te ayuda a ajustar el rendimiento del juego, revisar la telemetría del dispositivo en vivo y aplicar optimizaciones específicas para juegos compatibles con Android. Está pensado para jugadores que buscan mejor FPS, menor latencia, diagnósticos más claros y un control del sistema más receptivo.

## Funciones principales

- Spoofing de dispositivos y ajustes avanzados
- Editor de archivos de juego
- Monitor de FPS, CPU, RAM y temperatura
- Herramientas como crosshair y optimización DNS
- Soporte root y Shizuku

## Instalación

1. Descarga la aplicación desde la sección de releases.
2. Elige el método adecuado: root o Shizuku.
3. Sigue las instrucciones dentro de la app para configurar los juegos y aplicar ajustes.

## Compilar desde el código fuente

```bash
git clone https://github.com/catsmoker/com.catsmoker.app.git
cd com.catsmoker.app
./gradlew :app:compileFullDebugKotlin
```
