## نبذة عن المشروع

**مُدخّن القطط** حزمة أدوات لألعاب أندرويد، صُممت لتحسين الألعاب المدعومة، وإتاحة خيارات إعداد إضافية، ومراقبة أداء الجهاز.

## المزايا

- **تحسين الأداء:** تغيير هوية الجهاز الظاهرة للألعاب، وضبط معدل الإطارات، والتحكم في الدقة وكثافة العرض.
- **أدوات الألعاب:** عرض معدل الإطارات مباشرة، ومراقبة المعالج والذاكرة، وقياس الحرارة واستهلاك الطاقة.
- **التخصيص:** مؤشر تصويب عائم، وإعدادات DNS للألعاب، ومحرر لإعدادات الألعاب.
- **النظام:** التكامل مع صلاحيات النظام، وأدوات التشخيص، وسجلات النظام.
- **مكتبة الألعاب:** استعراض الألعاب المثبتة وتشغيلها وإدارتها.

## التنزيل والتثبيت

اختر **نسخة واحدة** حسب احتياجاتك. النسختان تابعتان للمشروع نفسه، لكنهما تختلفان في المزايا ومتطلبات التثبيت.

### طريقة التثبيت

**الخيار الأول — الأجهزة التي تمتلك صلاحيات الجذر**

المتطلبات: ماجيسك أو APatch أو KernelSU.

1. ثبّت وفعّل تطبيقاً واحداً فقط لتشغيل وحدات زيجيسك:
   - [ZygiskNext](https://github.com/LSPosed/ZygiskNext/releases)
   - [NeoZygisk](https://github.com/JingMatrix/NeoZygisk/releases)
   - [ReZygisk](https://github.com/PerformanC/ReZygisk)
2. ثبّت وحدة واحدة لإدارة الإضافات:
   - **الموصى بها:** [Vector](https://github.com/JingMatrix/Vector/releases)
   - البديل: [LSPosed](https://github.com/LSPosed/LSPosed)
3. أعد تشغيل الجهاز.
4. ثبّت مُدخّن القطط وامنحه صلاحيات الجذر.
5. افتح مدير Vector أو LSPosed، وفعّل وحدة مُدخّن القطط، ثم اختر الألعاب المستهدفة.
6. أوقف الألعاب المختارة إيقافاً إجبارياً، ثم شغّلها من جديد.

**مهم:** استخدم تطبيقاً واحداً فقط لتشغيل زيجيسك ووحدة واحدة فقط لإدارة الإضافات.

**الخيار الثاني — الأجهزة التي لا تمتلك صلاحيات الجذر (شيزوكا)**

1. ثبّت [Shizuku Next](https://github.com/ShizukuNext/ShizukuNext) أو [شيزوكا الرسمي](https://play.google.com/store/apps/details?id=moe.shizuku.privileged.api).
2. شغّل شيزوكا باستخدام التصحيح اللاسلكي أو ADB.
3. ثبّت مُدخّن القطط وامنحه إذن شيزوكا.
4. اختر لعبتك واستخدم الأدوات المتاحة التي تعمل عبر شيزوكا.

قد تحتاج بعض عمليات الملفات إلى صلاحيات إضافية عبر أداة اختيار الملفات في أندرويد أو مدير ملفات مثل ZArchiver.

- تستخدم إعلانات AdMob بدلاً من Start.io.
- تتطلب بعض المزايا المتقدمة أذونات خاصة أو توافقاً معيناً.

### الانضمام إلى الاختبار المغلق

نسخة Google Play متاحة حالياً عبر الاختبار المغلق.

1. انضم إلى مجموعة Google: **catsmoker-apps@googlegroups.com**
2. انتظر حتى خمس دقائق لتحديث صلاحية الوصول.
3. افتح [صفحة الاختبار على Google Play](https://play.google.com/apps/testing/com.catsmoker.app).
4. سجّل في الاختبار وثبّت مُدخّن القطط من المتجر.

</details>

- **دون صلاحيات الجذر:** شيزوكا أو إحدى طرق الوصول اليدوي المدعومة.

## البناء من المصدر

المتطلبات: Android Studio وJDK 17 وحزمة تطوير أندرويد والأدوات المخصصة للمشروع.

```bash
bash ./gradlew :app:assembleFullDebug :app:assemblePlaystoreDebug
```

توجد نسختان للبناء في الفرع الرئيسي:

| النسخة | أمر البناء |
|---|---|
| نسخة GitHub الكاملة | `:app:assembleFullRelease` |
| نسخة Google Play | `:app:assemblePlaystoreRelease` |

راجع [دليل بناء النسخ](docs/FLAVOR_WORKFLOW.md).

## الخصوصية

- **العمل محلياً:** تبقى الإعدادات والملفات التعريفية والنسخ الاحتياطية والسجلات على جهازك.
- لا يوجد نظام حسابات أو خادم خلفي تابع للمشروع.
- لا تغادر السجلات والتسجيلات جهازك إلا إذا اخترت مشاركتها بنفسك.
- تستخدم عملية التحقق من التحديثات واجهة إصدارات GitHub العامة.
- تستخدم النسخة الكاملة إعلانات Start.io، بينما تستخدم نسخة Google Play إعلانات AdMob.

يمكنك قراءة سياسة الخصوصية وشروط الاستخدام كاملة من داخل التطبيق عبر **حول ← الشؤون القانونية**.
