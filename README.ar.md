**CatSmoker** هي أداة تحسين للألعاب على Android تدعم الألعاب المتوافقة. تجمع بين التكاملات على مستوى النظام، وأدوات تعديل ملفات اللعبة، والتقارير الحية، والتحكم في الأداء داخل تطبيق واحد.

## نظرة عامة

يساعدك CatSmoker على ضبط أداء الألعاب، ومراقبة بيانات الجهاز مباشرة، وتطبيق تحسينات مستهدفة على الألعاب المدعومة. صُمم التطبيق للاعبين الذين يريدون أفضل معدل إطارات، وأقل تأخير، ومخرجات تشخيص أفضل، وضوابط أكثر استجابة.

## المزايا الرئيسية

- تحسينات الأجهزة والخصائص
- أدوات تحرير ملفات الألعاب
- مراقبة FPS وCPU وRAM والحرارة
- أدوات ألعاب مثل Crosshair وDNS
- دعم root وShizuku

## التثبيت

1. حمل التطبيق من صفحة الإصدارات.
2. اختر طريقة الوصول المناسبة: root أو Shizuku.
3. اتبع التعليمات داخل التطبيق لإضافة الألعاب وتطبيق التحسينات.

## التشغيل من المصدر

```bash
git clone https://github.com/catsmoker/com.catsmoker.app.git
cd com.catsmoker.app
./gradlew :app:compileFullDebugKotlin
```
