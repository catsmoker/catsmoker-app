# Contributing to CatSmoker

Thanks for helping. To keep things actionable, pick the right channel:

## Where to post

- **Bugs → Issues.** Use the **Bug Report** template and include CatSmoker
  version, Android version, device, and Root / Shizuku / neither.
- **Feature proposals → Issues or Discussions.** Use the **Feature Request**
  template for concrete, scoped proposals. Early or uncertain ideas fit better
  in [Discussions → Feature Ideas](https://github.com/catsmoker/catsmoker-app/discussions).
- **General questions → Discussions.** Questions, feedback, and community
  conversation belong in
  [Discussions](https://github.com/catsmoker/catsmoker-app/discussions),
  not Issues. You can also reach the community on
  [Discord](https://discord.com/invite/HQC5BwcXtS) or
  [Telegram](https://t.me/CATSM0KER).
- **Performance problems → Issues with details.** Use the **Performance Issue**
  template and include device, Android version, game (with package name),
  CatSmoker version, measured vs. expected FPS, thermal behaviour, active
  CatSmoker features, and Root / Shizuku status.

## Good reports

- **Logs when possible.** Attach a logcat or the in-app Engineering Console
  output, plus screenshots or overlay readings for performance reports.
- **No sensitive personal information.** Remove accounts, emails, tokens, and
  other private data before posting.
- One problem per issue. Check existing issues and discussions first to avoid
  duplicates.

Large changes: please open an issue before starting, as noted in the README.
