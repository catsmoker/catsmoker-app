## 概要

**CatSmoker** は、対応ゲームの最適化、追加設定オプションのアンロック、デバイスパフォーマンスの監視のために設計された Android ゲーミングツールキットです。

## 機能

| カテゴリ | 機能 |
|---|---|
| **最適化** | デバイススプーフィング、FPS 設定、解像度と DPI 制御 |
| **ゲームツール** | リアルタイム FPS オーバーレイ、CPU/RAM 監視、温度と電力テレメトリ |
| **カスタマイズ** | クロスヘアオーバーレイ、ゲーミング DNS、ゲーム設定エディタ |
| **システム** | Root/Shizuku 統合、診断、システムログ |
| **ゲームライブラリ** | インストール済みゲームの検出、起動、管理 |

### インストール方法

**オプション A — Root 環境 (LSPosed / Vector)**

前提条件: Magisk、APatch、または KernelSU。

1. Zygisk 実装を **1 つだけ** インストールして有効化:
   - [ZygiskNext](https://github.com/LSPosed/ZygiskNext/releases)
   - [NeoZygisk](https://github.com/JingMatrix/NeoZygisk/releases)
   - [ReZygisk](https://github.com/PerformanC/ReZygisk)
2. フレームワークモジュールを **1 つだけ** インストール:
   - **推奨:** [Vector](https://github.com/JingMatrix/Vector/releases)
   - 代替: [LSPosed](https://github.com/LSPosed/LSPosed)
3. デバイスを再起動。
4. CatSmoker をインストールし、Root 権限を付与。
5. Vector または LSPosed マネージャーを開き、CatSmoker モジュールを有効化して対象ゲームを選択。
6. 選択したゲームを強制停止して再起動。

**重要:** Zygisk 実装は 1 つだけ、フレームワークモジュールも 1 つだけ使用してください。

**オプション B — 非 Root 環境 (Shizuku)**

1. [Shizuku Next](https://github.com/ShizukuNext/ShizukuNext) または [公式 Shizuku](https://play.google.com/store/apps/details?id=moe.shizuku.privileged.api) をインストール。
2. ワイヤレスデバッグまたは ADB で Shizuku を起動。
3. CatSmoker をインストールし、Shizuku 権限を付与。
4. ゲームを選択し、Shizuku で動作する利用可能なツールを使用。

一部のファイル操作には、SAF または ZArchiver などのファイルマネージャーによる追加アクセスが必要な場合があります。

</details>

<summary><strong>Google Play 版 — 非 Root エディション</strong></summary>

**Root 不要で Google Play からインストールしたいユーザー向け。**

<a href="https://play.google.com/apps/testing/com.catsmoker.app">

**違い:**
- Root や LSPosed が不要。
- デバイススプーフィング、Magisk モジュール生成、GitHub 自己アップデータは含まれない。
- Start.io ではなく AdMob 広告を使用。
- 一部の高度な機能は個別の権限や互換性要件を保持。

### クローズドテストへの参加

Google Play 版は現在クローズドテストで提供されています。

1. Google グループに参加: **catsmoker-apps@googlegroups.com**
2. 最大 5 分間、アクセス更新を待機。
3. [Google Play テストページ](https://play.google.com/apps/testing/com.catsmoker.app) を開く。
4. テストに登録し、Google Play から CatSmoker をインストール。

</details>

> **どちらを選ぶか迷ったら?** 高度な Root 機能が必要なら GitHub 完全版を、標準的な非 Root 版を好むなら Google Play 版を選んでください。

## 互換性

- **最小 Android バージョン:** 8.1 (API 27)。
- **Root 環境:** Magisk、APatch、または KernelSU (対応する Zygisk/フレームワーク設定必須)。
- **非 Root 環境:** Shizuku または対応する手動アクセス方法。

テスト済みデバイス:
- POCO X3 NFC
- Nothing Phone (2a)
- Xiaomi Redmi Note 14
- Lenovo Legion Tab
- Realme 9 Pro Plus

## ソースからビルド

要件: Android Studio、JDK 17、Android SDK、プロジェクト設定済みの NDK。

```bash
bash ./gradlew :app:assembleFullDebug :app:assemblePlaystoreDebug
```

`main` ブランチでは 2 つの Gradle フレーバーを維持:

| バリアント | ビルドタスク |
|---|---|
| GitHub 完全版 | `:app:assembleFullRelease` |
| Google Play 版 | `:app:assemblePlaystoreRelease` |

詳細は [フレーバーワークフロー](docs/FLAVOR_WORKFLOW.md) を参照。

## プライバシー

- **ローカルファースト:** 設定、プロファイル、バックアップ、ログはデバイスに残る。
- アカウントシステムやプロジェクト運営のバックエンドは存在しない。
- 診断ログはユーザーが明示的に共有しない限りデバイス外に出ない。音声、動画、画面は録画しない。
- アップデート確認にはパブリック GitHub Releases API を使用。
- 完全版: Start.io 広告。Google Play 版: AdMob 広告。

アプリ内の **About → Legal** から完全なプライバシーポリシーと利用規約を確認できます。
