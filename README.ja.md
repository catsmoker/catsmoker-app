**CatSmoker** は、対応ゲーム向けの Android 最適化ユーティリティです。システムレベルの連携、ゲーム設定の編集、ライブ計測、ゲーム向けコントロールを 1 つのアプリでまとめています。

## 概要

CatSmoker は、ゲームのパフォーマンス調整、端末のテレメトリ確認、対応 Android ゲームへの最適化適用を支援します。より高い FPS、低いレイテンシ、より明確な診断、よりレスポンスの高いシステム制御を求めるプレイヤー向けに設計されています。

## 主な機能

- デバイスの偽装と高度な最適化
- ゲームファイル編集ツール
- FPS、CPU、RAM、温度の監視
- クロスヘアや DNS 最適化などのゲーム機能
- root / Shizuku 対応

## インストール

1. Releases からアプリをダウンロードします。
2. root または Shizuku の方法を選びます。
3. アプリ内の案内に従ってゲームを追加し、最適化を適用します。

## ソースコードからビルド

```bash
git clone https://github.com/catsmoker/com.catsmoker.app.git
cd com.catsmoker.app
./gradlew :app:compileFullDebugKotlin
```
