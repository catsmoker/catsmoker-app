**CatSmoker** é um utilitário de otimização para Android voltado a jogos compatíveis. Ele combina integrações de sistema, ferramentas para editar arquivos de jogo, telemetria em tempo real e controles focados em desempenho em um único app.

## Visão geral

O CatSmoker ajuda você a ajustar o desempenho do jogo, verificar a telemetria do dispositivo em tempo real e aplicar otimizações direcionadas para jogos Android compatíveis. O app foi pensado para jogadores que desejam melhor FPS, menor latência, diagnósticos mais claros e controles mais responsivos do sistema.

## Principais recursos

- Spoofing de dispositivo e ajustes avançados
- Ferramentas de engenharia de arquivos de jogo
- Monitor de FPS, CPU, RAM e temperatura
- Recursos como crosshair e otimização de DNS
- Suporte a root e Shizuku

## Instalação

1. Baixe o app na seção de releases.
2. Escolha o método adequado: root ou Shizuku.
3. Siga as instruções dentro do app para adicionar jogos e aplicar otimizações.

## Compilar a partir do código-fonte

```bash
git clone https://github.com/catsmoker/com.catsmoker.app.git
cd com.catsmoker.app
./gradlew :app:compileFullDebugKotlin
```
