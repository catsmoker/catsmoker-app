## Sobre

**CatSmoker** é um conjunto de ferramentas para jogos Android projetado para otimizar jogos compatíveis, desbloquear opções de configuração adicionais e monitorar o desempenho do dispositivo.

## Recursos

| Categoria | Recursos |
|---|---|
| **Otimização** | Spoofing de dispositivo, configurações de FPS, controles de resolução e DPI |
| **Ferramentas para Jogos** | Overlay de FPS em tempo real, monitoramento de CPU/RAM, telemetria de temperatura e energia |
| **Personalização** | Overlay de crosshair, DNS para jogos, editor de configuração de jogos |
| **Sistema** | Integração Root/Shizuku, diagnósticos, logs do sistema |
| **Biblioteca de Jogos** | Descobrir, iniciar e gerenciar jogos instalados |

### Instalação

**Opção A — Dispositivos com Root (LSPosed / Vector)**

Pré-requisitos: Magisk, APatch ou KernelSU.

1. Instale e ative **uma única** implementação de Zygisk:
   - [ZygiskNext](https://github.com/LSPosed/ZygiskNext/releases)
   - [NeoZygisk](https://github.com/JingMatrix/NeoZygisk/releases)
   - [ReZygisk](https://github.com/PerformanC/ReZygisk)
2. Instale **um único** módulo de framework:
   - **Recomendado:** [Vector](https://github.com/JingMatrix/Vector/releases)
   - Alternativa: [LSPosed](https://github.com/LSPosed/LSPosed)
3. Reinicie o dispositivo.
4. Instale o CatSmoker e conceda acesso root.
5. Abra o gerenciador do Vector/LSPosed, ative o módulo CatSmoker e selecione seus jogos alvo.
6. Force a parada dos jogos selecionados e reinicie-os.

**Importante:** Use apenas uma implementação de Zygisk e um único módulo de framework.

**Opção B — Dispositivos sem Root (Shizuku)**

1. Instale o [Shizuku Next](https://github.com/ShizukuNext/ShizukuNext) ou o [Shizuku oficial](https://play.google.com/store/apps/details?id=moe.shizuku.privileged.api).
2. Inicie o Shizuku usando Depuração Sem Fio ou ADB.
3. Instale o CatSmoker e conceda permissão do Shizuku.
4. Selecione seu jogo e use as ferramentas disponíveis que funcionam via Shizuku.

Algumas operações de arquivo podem exigir acesso adicional via SAF ou um gerenciador de arquivos como o ZArchiver.

## Compatibilidade

- **Android mínimo:** 8.1 (API 27).
- **Com Root:** Magisk, APatch ou KernelSU com configuração compatível de Zygisk/framework.
- **Sem Root:** Shizuku ou métodos de acesso manual compatíveis.

Dispositivos testados incluem:

- POCO X3 NFC
- Nothing Phone (2a)
- Xiaomi Redmi Note 14
- Lenovo Legion Tab
- Realme 9 Pro Plus

## Compilar a partir do Código Fonte

Requisitos: Android Studio, JDK 17, Android SDK e NDK configurado para o projeto.

```bash
bash ./gradlew :app:assembleFullDebug :app:assemblePlaystoreDebug
```

Duas variantes Gradle são mantidas na branch `main`:

| Variante | Tarefa de Build |
|---|---|
| GitHub Completa | `:app:assembleFullRelease` |
| Google Play | `:app:assemblePlaystoreRelease` |

Consulte o [fluxo de trabalho das variantes](docs/FLAVOR_WORKFLOW.md).

## Privacidade

- **Local-first:** configurações, perfis, backups e logs ficam no seu dispositivo.
- Não há sistema de contas nem backend operado pelo projeto.
- Logs de diagnóstico saem do dispositivo apenas quando compartilhados explicitamente; o app não grava áudio, vídeo ou tela.
- Verificações de atualização usam a API pública do GitHub Releases.
- Versão completa: anúncios Start.io. Versão Google Play: anúncios AdMob.

Leia a Política de Privacidade e Termos completos dentro do app em **Sobre → Legal**.

## Aviso Legal

Modificar arquivos de jogos ou fazer spoofing da identidade do dispositivo pode violar os Termos de Serviço de jogos individuais. Use o CatSmoker com responsabilidade. Os desenvolvedores não se responsabilizam por bans de conta, problemas de hardware ou bootloops.
